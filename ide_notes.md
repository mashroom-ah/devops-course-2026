# Git в VS Code: что удобно, а что нет

## Что удобно в VS Code

1. **Кнопки вместо команд** — не надо помнить `git add`, `git commit`, `git push`. Просто нажал на галочку или стрелочку — и готово.
2. **Видно, какие файлы изменились** — в панели Source Control сразу список: какой файл новый, какой изменён, какой удалён. Не надо вводить `git status`.
3. **Цветные полоски в редакторе** — рядом с изменёнными строками появляются зелёные, синие и красные метки. Сразу видно, где что поменялось.

## Что удобнее в терминале

- **Когда что-то пошло не так** — если VS Code выдаёт непонятную ошибку, в терминале проще понять, что случилось, и исправить вручную.
