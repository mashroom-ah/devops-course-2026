# Мой пет-проект

Идея: Сайт-визитка для фрилансера (например, веб-разработчика или дизайнера). Одностраничный лендинг с краткой информацией о себе, списком услуг, портфолио из нескольких работ и формой обратной связи. Дополнительно — тёмная/светлая тема и адаптивная вёрстка под мобильные устройства.
Стек: React, Node.js + Express, PostgreSQL
Цель: научиться строить fullstack-приложение с нуля — связать React с REST API на Express, реализовать CRUD, авторизацию через JWT, защиту админ-роутов и работу с базой данных. Получить реальное портфолио-приложение, которое можно показывать заказчикам и развивать дальше.
